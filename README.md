# Realistic Dark Brotherhood Kidnapping

A small quality of life mod, which conditions the Astrid's attempt to kidnap the player to only occur at specific times or in specific locations.  
The mod can be configured using a `.json` file, 3 presets are available which pre configure the mod to only allow kidnappings at specific times and/or locations.  
Precompiled and properly packaged versions can be downloaded on [Nexus Mods](https://www.nexusmods.com/skyrimspecialedition/mods/68260)).

The project is designed such that it does not allocate any memory in the save file whatsoever, allowing the mod to be added or removed at any point in time.
