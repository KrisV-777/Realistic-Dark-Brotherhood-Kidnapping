# Realistic Dark Brotherhood Kidnapping ([Nexus Mods Mirror](https://www.nexusmods.com/skyrimspecialedition/mods/68260))

A small quality of mod, which conditions the Astrid's attempt to kidnap the player to only occur at specific times or in specific locations.  
The repository combines all 3 attempts in a single script, with makeshift commenting out relevant code blocks (certainly something that should be improved at some point in time), I therefore highly recommend to download the mod from Nexus instead.

The project is designed such that it does not allocate any memory in the save file whatsoever, allowing the mod to be added or removed at any point in time.
